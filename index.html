YouRSS Helm repository

An alternative front-end to YouTube built on the RSS feeds YouTube publishes for every channel and playlist: the latest videos of the channels you chose, on one page. No account, no ads, no recommendations, no tracking.

Install with Helm

You need access to a Kubernetes cluster and the helm tool.

# add the repository
helm repo add yourss https://essembeh.github.io/YouRSS/
# get the values and edit them for your needs
helm show values yourss/yourss > myvalues.yaml
# install a release
helm install my-yourss yourss/yourss -f myvalues.yaml

The chart deploys a single stateless Deployment with its Service, and optionally an Ingress, a HorizontalPodAutoscaler and a Secret holding the users and their pages. Without an ingress, forward the service to try it, then open http://localhost:8000/:

kubectl port-forward service/my-yourss 8000:http

The chart version follows the application version: appVersion is the default image tag. Every value under yourss maps to one YOURSS_* variable, with the same default as the application; see the chart documentation.

Install with Flux

apiVersion: source.toolkit.fluxcd.io/v1
kind: HelmRepository
metadata:
  name: yourss
spec:
  interval: 1h
  url: https://essembeh.github.io/YouRSS/
---
apiVersion: helm.toolkit.fluxcd.io/v2
kind: HelmRelease
metadata:
  name: yourss
spec:
  interval: 10m
  chart:
    spec:
      chart: yourss
      version: "*"  # or pin a version
      sourceRef:
        kind: HelmRepository
        name: yourss
  values:
    yourss:
      cacheEnabled: true

Run with Docker

docker run -d --name yourss -p 8000:8000 ghcr.io/essembeh/yourss:main
